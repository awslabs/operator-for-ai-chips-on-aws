# implement

Read `.kiro/skills/implement/skills/controller.md` and follow it.

Ask me what I want to do — do not assume an issue or a phase:

- If starting fresh, ask for the GitHub issue URL or number, then run the
  **ingest** phase.
- If work is already in progress (artifacts exist under
  `.artifacts/implement/<issue-id>/`), ask which phase to run next — plan,
  revise, code, validate, or respond — and proceed.
