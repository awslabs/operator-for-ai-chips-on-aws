# implement · ingest

Read `.kiro/skills/implement/skills/controller.md` and follow it; dispatch the
**ingest** phase.

The GitHub issue is the phase input. Use the issue URL or number from the
current message if one is present. If none is present, **ask me for the GitHub
issue URL or number and wait** — do not assume or invent one.

> Note: on Kiro, `@`-invoking this prompt does not forward text typed after it.
> The reliable way to run this is to state the issue in your message, e.g.
> "ingest https://github.com/owner/repo/issues/65", to the `implement` agent.
